# Lucid Cats Chat — Text Chat Mod

A BepInEx mod that adds text chat to Lucid Cats.

## Requirements

**BepInEx 5 x64** (5.4.23.5 or newer) — required, and NOT bundled with this mod.

## Installing BepInEx

1. Download **BepInEx_x64_5.4.23.5.zip** (the x64 build) from:
   https://github.com/BepInEx/BepInEx/releases
2. Extract the archive into the game folder so these files sit next to `Lucid Cats.exe`:
   - `winhttp.dll`
   - `doorstop_config.ini`
   - `BepInEx\` folder
3. Launch the game once. BepInEx will generate its subfolders (`BepInEx\plugins`, etc.) 
4. Verify: a `BepInEx\LogOutput.log` file appears in the game folder.

## Installing this mod

1. Make sure BepInEx is installed (see above).
2. Extract the `BepInEx` folder from this archive into the game folder and merge it.
   The final files should be at:
   - `BepInEx/plugins/LucidCatsChat.dll`
   - `BepInEx/plugins/cnfont.ttf`
3. Launch the game.

## Usage

- In a game scene, press **Enter** to open the chat
- Type your message and press **Enter** to send
- Press **Esc** to cancel
- The chat fades out automatically after sending

# Lucid Cats Chat — 文字聊天模组

为 Steam 游戏《Lucid Cats》添加文字聊天的 BepInEx 模组。


## 前置要求

**BepInEx 5 x64**（5.4.23.5 或更新）——必需前置，本模组不包含。

## 安装 BepInEx

1. 从下面地址下载 **BepInEx_x64_5.4.23.5.zip**（选择 x64 版本）：
   https://github.com/BepInEx/BepInEx/releases
2. 将压缩包解压到游戏根目录，使以下文件与 `Lucid Cats.exe` 同级：
   - `winhttp.dll`
   - `doorstop_config.ini`
   - `BepInEx\` 文件夹
3. 启动游戏一次，BepInEx 会自动生成子目录（`BepInEx\plugins` 等）
4. 验证：游戏目录下出现 `BepInEx\LogOutput.log`。

## 安装本模组

1. 确保已安装 BepInEx（见上）。
2. 将本压缩包内的 `BepInEx` 文件夹解压到游戏根目录并合并。
   最终文件应位于：
   - `BepInEx/plugins/LucidCatsChat.dll`
   - `BepInEx/plugins/cnfont.ttf`
3. 启动游戏。

## 使用

- 进入游戏场景后，按 **回车（Enter）** 唤起聊天框
- 输入文字，按 **回车** 发送
- **Esc** 取消输入
- 消息发送后会自动淡出隐藏

## 汉化联动

- 若同时安装了汉化补丁（LucidCatsCN），聊天提示会自动显示中文；否则显示英文。
